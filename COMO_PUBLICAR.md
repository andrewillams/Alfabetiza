# 🚀 Como Publicar o Joguinho Online

## Passo a Passo Super Simples (3 minutos)

### ✅ Já está quase pronto!
Eu criei um sistema de deploy automático. Agora você só precisa fazer **3 cliques** no GitHub:

---

## 📍 OPÇÃO 1: Configuração Automática (Recomendado)

### Passo 1: Acesse as Configurações
1. Vá para: https://github.com/andrewillams/Alfabetiza
2. Clique em **Settings** (engrenagem no menu superior)
3. No menu lateral esquerdo, clique em **Pages**

### Passo 2: Configure o Source
Na seção **Build and deployment**:
- Em **Source**, selecione: **GitHub Actions**
- (Se já estiver selecionado, pule para o Passo 3)

### Passo 3: Ative o Workflow
1. Clique na aba **Actions** (no topo do repositório)
2. Se aparecer um botão verde **"I understand my workflows, go ahead and enable them"**, clique nele
3. Clique no workflow **"Deploy to GitHub Pages"**
4. Clique em **"Run workflow"** → **"Run workflow"**

### Passo 4: Aguarde (1-2 minutos)
- O GitHub vai processar e publicar automaticamente
- Você verá um check verde ✅ quando estiver pronto

### Passo 5: Acesse seu jogo! 🎉
Seu joguinho estará disponível em:
```
https://andrewillams.github.io/Alfabetiza/
```

---

## 📍 OPÇÃO 2: Configuração Manual (Alternativa)

Se a Opção 1 não funcionar, tente esta:

### Passo 1: Settings → Pages
1. Vá para: https://github.com/andrewillams/Alfabetiza/settings/pages
2. Em **Source**, selecione: **Deploy from a branch**
3. Em **Branch**, selecione: **claude/kids-word-game-011PbCZkcSGuLd2SFLvcj67Y**
4. Pasta: **/ (root)**
5. Clique em **Save**

### Passo 2: Aguarde
- GitHub vai processar (1-2 minutos)
- Atualize a página
- Você verá uma mensagem: **"Your site is live at..."**

### Passo 3: Acesse
```
https://andrewillams.github.io/Alfabetiza/
```

## 🆘 Se Algo Der Errado

### Erro 1: "GitHub Pages não aparece nas Settings"
**Solução:** Certifique-se que o repositório é público (Settings → Danger Zone → Change visibility)

### Erro 2: "Site não carrega / 404"
**Solução:** Aguarde mais alguns minutos. O primeiro deploy pode demorar até 5 minutos.

### Erro 3: "Actions desabilitadas"
**Solução:** Vá em Settings → Actions → General → Allow all actions → Save
